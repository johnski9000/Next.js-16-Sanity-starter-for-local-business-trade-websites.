## How to use this
Each row is an EXISTING page already ranking at position 8-25 for a real query with >=30 impressions/90d - close to page 1 but not yet earning clicks. IMPROVE THE LISTED PAGE to better satisfy that query: sharpen the title/H1/H2 toward the query, add the depth/FAQs/examples/specifics it lacks, and add internal links from related pages. Do NOT create a new competing page - enhance the one listed (creating a competitor splits the ranking signal). Work top-down: rows are sorted by opportunity = impressions x closeness to page 1.
